Это приложение показывает баланс существующих кошельков и позволяет проводить операции пополнения или снятия суммы с баланса.

Изначально есть два кошелька: user1-wallet и user2-wallet. Для отображения баланса отправьте запрос: GET api/v1/wallets/{WALLET_UUID}, где WALLET_UUID - это название кошелька (например, user1-wallet).

Для проведения операции отправьте запрос: POST api/v1/wallet
{
valletId: UUID,
operationType: DEPOSIT or WITHDRAW,
amount: 1000
}

где DEPOSIT - увеличение баланса, а WITHDRAW - снятие суммы с баланса.
